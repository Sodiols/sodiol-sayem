# Reference analysis

Source: `Video Project 5.mp4`, 2520 × 1080, 6.466667 seconds.
Reviewed the complete sequence at 30 frame samples per second, with enlarged entrance,
exit, and homepage-reveal contact sheets in the local ignored `.reference/` folder.
Black recording margins are not part of the website and are not reproduced.

| Time | Observed behavior | Implementation |
| --- | --- | --- |
| 0–0.83s | Empty opening surface | Solid muted olive; no photo or added graphics |
| 0.83–1.58s | Alternating displaced glyphs assemble, slight opposing tilts | Seven independently animated glyphs; 0–350ms stagger with shorter later durations; em-based travel |
| 1.58–2.48s | Aligned, still word | Centered `sodiol.` with baseline and tight tracking |
| 2.48–3.11s | Glyphs separate in opposite vertical directions and lose opacity | Opposing exit travel, accelerated separation, compressed stagger |
| 3.11–3.78s | Empty surface hold | Overlay remains fully opaque and stationary |
| 3.78–4.24s | Full opening surface rises off screen | One continuous translated surface over a dark curtain |
| 4.24–4.92s | Dark interlude | Static dark curtain |
| 4.92–5.74s | Navigation appears and content uncovers from left to right | Prepared portfolio under a right-anchored horizontal curtain; staggered content settling |

The recording shows alternating vertical movement and mild rotation, not a
typewriter or random scatter. The longer word keeps the entrance inside the same
time window rather than appending extra stagger time. Exit continues that visual
language in opposing directions.

The original font cannot be conclusively identified from these raster frames.
Instrument Serif is an open-source approximation selected for its high stroke
contrast, compact lowercase shapes, and delicate serifs. It is not claimed to be
the exact reference typeface. Source and license:
https://github.com/Instrument/instrument-serif

The opening's solid color and the new portfolio content are adaptations authorized
by the brief and subsequent instruction to start from scratch. No photographic
assets or homepage design from the reference are reused.
