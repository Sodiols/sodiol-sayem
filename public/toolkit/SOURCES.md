# Toolkit assets

The 20 named Simple Icons SVG files are sourced from the Simple Icons project's
`develop/icons` directory: https://github.com/simple-icons/simple-icons/tree/develop/icons
The local CC0 license is at `../licenses/Simple-Icons.txt`.

`vscode.svg` is the VS Code original icon from Devicon:
https://github.com/devicons/devicon/blob/master/icons/vscode/vscode-original.svg
The Devicon MIT license is at `../licenses/Devicon.txt`.

SVG shapes are unchanged. CSS renders them as monochrome marks. Brand names and
logos identify the actual tools, and do not imply endorsement. Claude Code uses
the Claude identity. Codex, Google AI Studio, Google Antigravity and REST APIs use
typeset names rather than an invented or unverified product symbol.
